# 📝 To-Do List App

A simple and interactive To-Do List application built using HTML, CSS, and JavaScript.

The app allows users to add, edit, delete, and complete tasks. Tasks are stored in the browser's LocalStorage, so they remain available even after refreshing the page.

## 🚀 Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- 📊 Track completed and uncompleted tasks
- 💾 Save tasks using LocalStorage
- 🔄 Tasks persist after page refresh
- 🚫 Input validation for empty tasks
- 📱 Responsive layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- LocalStorage
